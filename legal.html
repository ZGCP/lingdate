第一条 网站性质与定位

1.1 示例部署声明：本站系由个人开发者独立维护的开源技术演示项目，为灵应用商店的示例部署版，与灵应用商店官方团队（ziling.xin）无任何隶属、合作或关联关系。本站不冒充官方身份，不构成任何"官方分支"，所有内容仅作技术交流与学习研究之用。

1.2 技术拓展工具定位：本站旨在提供更丰富的应用浏览、搜索、排序等拓展功能，优化用户体验。本站不托管、不镜像、不篡改任何应用文件，所有应用内容及版权归原作者所有。

1.3 非分发平台承诺：本站并非应用分发平台，仅作为官方 API 的前端展示层与功能拓展层。

第二条 数据来源与 API 使用合法性 合规

2.1 数据来源：所有应用元数据均来自灵应用商店官方公开 API（market.ziling.xin/api/v3）。本站仅缓存公开元数据用于展示，所有下载链接及实时数据最终指向 ziling.xin 官方域名。

2.2 API 使用授权依据：本站作为官方公开 API 的合法调用方，依据以下原则使用 API 数据：

  • 仅调用官方公开开放的、未要求鉴权的接口；
  • 缓存数据范围严格限定于公开元数据，不抓取未公开或需授权的内容；
  • 不进行高频并发请求，遵守官方接口限流规则；
  • 不对外转售、再分发官方 API 数据；
  • 如官方团队明确要求停止特定接口的调用，本站将立即响应。

2.3 缓存范围与层级：本站仅缓存应用列表、分类、应用详情三类公开数据，排行榜、捐赠榜、评论、通知、用户信息等其他数据均不缓存、实时获取。缓存分两个层级：（1）代理层面缓存，用于加速公开数据分发；（2）用户本地浏览器缓存（localStorage），仅保存登录令牌与偏好设置。应用列表数据每日更新 5 次（北京时间 00:00、06:00、12:00、18:00、22:00）。

2.4 降级容错机制：当缓存数据不可用时，前端将自动降级为实时 API 调用模式。

2.5 数据准确性豁免：本站对数据的准确性、完整性、及时性不作任何担保，所有数据仅供参考，请以 ziling.xin 官方渠道 为准。

第三条 隐私政策与个人信息保护

3.1 信息收集范围：本站为纯前端展示页面，在您未登录前，不收集您的任何个人信息。仅在您主动使用账号登录时，本站才会临时接收您填写的用户名、邮箱、密码，并同步转发至官方 API 用于身份验证、获取您的个人数据；上述登录凭据本站前端不存储、不落盘。验证通过后，登录令牌（Token）仅保存在您的浏览器本地（localStorage）。此外，页面上展示的应用、排行榜、评论等均为公开的缓存数据（非实时数据），不涉及收集您的个人隐私信息。

3.2 信息使用目的：临时转发的登录信息仅用于调用官方 API 完成身份验证与获取您授权的个人数据，不用于任何商业营销或未经授权的用途。本站不因您的浏览、搜索、查看应用等操作而记录您的个人信息。

3.3 密码安全 已明确：本站作为前端展示层，不以明文形式记录、保存或传输您的密码，密码在提交时经 HTTPS 加密通道发送给第三方 API 服务提供方。密码的哈希存储与校验由该服务方负责；本站前端代码中不写入、不打印、不落盘任何密码明文。我们建议您使用独立、强度足够的密码并定期更换。若您基于本站源码自建后端，请采用业界主流的慢哈希算法（如 bcrypt / Argon2id）配合随机盐与多轮迭代存储密码，切勿使用 SHA-256 等快哈希。

3.4 数据存储与跨境传输 已明确：本站为示例部署，不自建数据库。您的账号资料、评论、评分、收藏等数据由第三方 API 服务提供方（灵应用商店官方）存储与处理；本站仅在浏览器本地（localStorage）保存登录凭据与偏好设置。关于数据存储与跨境传输，特此说明：

  • 第三方服务方的服务器可能部署于中国境内或境外（含香港等地区），相关数据可能跨境传输与处理；
  • 本站不在自有服务器上留存上述数据，也不向无关第三方出售或披露；
  • 继续使用本站即视为您已知晓并同意上述存储与跨境传输安排。

3.5 登录后数据流转与传输安全：仅在您使用登录后的功能（如发表评论、评分、下载应用等）时，本站才会将您浏览器本地保存的登录令牌（Token）经代理转发至官方原服务器，用于鉴权并获取相应数据。传输全程采用 HTTPS 端到端加密；在代理转发环节，我们无法保证第三方代理不会收集您的数据，但得益于端到端加密，通常不会泄露，我们对此不作绝对保证。

3.6 用户权利：您有权查阅、更正、删除您的个人信息，以及注销账号。如需行使上述权利，请通过本页底部"联系方式"中的任一渠道联系我们。

3.7 Cookie 与本地存储：本站使用 localStorage 存储登录状态和用户偏好设置，不使用跟踪类 Cookie，不进行用户行为追踪分析。
